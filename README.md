# Codex++ Dream Skin 分支

这是 [BigPizzaV3/CodexPlusPlus](https://github.com/BigPizzaV3/CodexPlusPlus) 的个人维护分支。上游项目为 OpenAI Codex / ChatGPT 桌面应用提供外部启动器、供应商配置、会话管理与界面增强；本分支不会向上游提交 PR。

## 本分支改动

- 基于上游 `v1.2.53`。
- 集成 Codex-Dream-Skin `v1.5.14` 运行时和主题配色支持。
- 兼容新版 Codex 的 CSS Module 主内容区、顶部淡化层与设置页面。
- 保留 Dream Skin 的自定义背景、完整色板和实时皮肤更新能力。

## Windows 构建

GitHub Releases 提供两个 Windows 可执行文件：

- `codex-plus-plus.exe`：启动器。
- `codex-plus-plus-manager.exe`：管理工具。

从管理工具配置完成后，使用启动器打开 Codex。原项目的使用说明、功能列表和安装文档请参考上游仓库。
