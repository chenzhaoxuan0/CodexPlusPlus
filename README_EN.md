# Codex++ Dream Skin Branch

This is a personal maintenance branch of [BigPizzaV3/CodexPlusPlus](https://github.com/BigPizzaV3/CodexPlusPlus). The upstream project is an external launcher and manager for the OpenAI Codex / ChatGPT desktop app. This branch is not intended for upstream pull requests.

## Branch Changes

- Based on upstream `v1.2.52`.
- Integrates the Codex-Dream-Skin `v1.5.14` runtime and theme color support.
- Supports the current Codex CSS Module main surface, top fade, and settings page.
- Keeps custom Dream Skin backgrounds, complete color palettes, and live skin updates.

## Windows Builds

GitHub Releases include two Windows executables:

- `codex-plus-plus.exe`: launcher.
- `codex-plus-plus-manager.exe`: manager.

Configure Codex in the manager, then launch it through the launcher. Refer to the upstream repository for complete usage, feature, and installation documentation.
